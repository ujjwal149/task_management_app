# Task Management App

A full-stack Task Management application built with modern web technologies.

## Tech Stack

### Frontend
- Next.js 16
- React
- TypeScript
- Tailwind CSS
- Axios

### Backend
- Node.js
- Express.js
- TypeScript
- Prisma ORM
- PostgreSQL (Neon)
- JWT Authentication
- Zod Validation
- bcrypt

## Features

- User Authentication
- Role-Based Authorization (Admin/User)
- Task CRUD Operations
- Protected Routes
- Pagination
- REST API
- Cookie-based Authentication

## Project Structure

```
task_management_app/
│
├── client/
│
└── server/
```

## Installation

### Backend

```bash
cd server
npm install
npm run dev
```

### Frontend

```bash
cd client
npm install
npm run dev
```
